# CodeSamplesJobStatus

The current status of the job. Possible values are `pending` or `running`.

## Example Usage

```ruby
require "speakeasy_client_sdk_ruby"

value = CodeSamplesJobStatus::PENDING
```


## Values

| Name      | Value     |
| --------- | --------- |
| `PENDING` | pending   |
| `RUNNING` | running   |
