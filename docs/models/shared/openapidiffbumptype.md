# OpenapiDiffBumpType

Bump type of the lock file (calculated semver delta, or a custom change (manual release))

## Example Usage

```ruby
require "speakeasy_client_sdk_ruby"

value = OpenapiDiffBumpType::MAJOR
```


## Values

| Name    | Value   |
| ------- | ------- |
| `MAJOR` | major   |
| `MINOR` | minor   |
| `PATCH` | patch   |
| `NONE`  | none    |
